# ROADLIVE — Живая карта для автомобилистов

> **Что происходит на дороге прямо сейчас.**  
> Спроси. Подтверди. Поезжай.

Production-ready веб-приложение для автомобилистов с живой дорожной обстановкой в реальном времени.

---

## 🚀 Основные возможности

1. **Полноэкранная живая карта (Leaflet + OpenStreetMap)**
   - 🚧 **Ж/Д переезды**: статус закрыт/открыт, длина очереди, актуальность
   - 🚗 **ДТП**: мелкие, крупные, перекрытие полос или дороги
   - 👮 **Дорожный контроль**: экипажи проверки документов и контроля скорости
   - ⛽ **АЗС**: цены на топливо (АИ-92, 95, 98, ДТ) и статус очереди (свободно, 2–4 авто, большая очередь)
   - 🛣️ **Дорога**: ремонт, глубокие ямы с арматурой, подтопления, гололёд, перекрытия
   - 🚦 **Светофоры**: неисправности, мигающий жёлтый
   - 🚚 **Препятствия**: сломавшиеся фуры, посторонние предметы на полосе
   - ❓ **Вопросы водителей**: прямая связь водителей в конкретной точке

2. **Быстрое создание события (1-click сценарии)**
   - 🚧 Переезд → Закрыт → Опубликовать (без лишнего ввода)
   - ⛽ АЗС → Большая очередь → Опубликовать
   - 👮 Дорожный контроль → Опубликовать
   - 🚗 ДТП → Опубликовать
   - Защита от спама и предупреждение о дубликатах в радиусе 250м
   - Предупреждение о безопасности водителя: *«Не пользуйтесь телефоном за рулём»*

3. **Система подтверждений и «Я здесь»**
   - Учёт расстояния до события: если водитель находится рядом (≤1500м), подтверждение имеет высокий вес.
   - Если водитель далеко: подтверждение принимается с пометкой об удалённом статусе.
   - Кнопка *«Уже не актуально»* для быстрого снятия ложных меток.

4. **Автоматическое старение и TTL**
   - У каждого типа события свой жизненный цикл:
     - Переезд: 20 мин после последнего подтверждения
     - ДТП: 45–60 мин
     - Дорожный контроль: 25 мин
     - Очередь на АЗС: 25 мин
     - Ремонт / ямы: от 2 дней до 2 недель
   - Индикаторы актуальности:
     - 🟢 **Сейчас актуально**
     - 🟡 **Информация устаревает**
     - ⚪ **Возможно уже неактуально**

5. **Лента вопросов автомобилистов (/questions)**
   - Фильтры: *Все, Новые, Без ответа, Популярные*
   - Вопросы прямо с карты с точным адресом и расстоянием
   - Система ответов с отметкой *«Полезно»* и верификацией экспертами района

6. **Живой чат и водительская рация (/chat, WebSocket)**
   - Реальное серверное WebSocket-соединение (`/ws/chat`) с мгновенной синхронизацией сообщений между всеми водителями.
   - Тематические каналы:
     - 📻 **Общий эфир (Новосибирск)**
     - 🌉 **Мосты и переправы** (Димитровский, Октябрьский, Бугринский)
     - 🚧 **Ж/Д Переезды** (Троллейная, Станционная, Бетонная)
     - 🏙️ **Районные каналы** (Ленинский, Октябрьский, Центральный)
   - Быстрые шаблоны для водителей за рулём (1 тап): *«Димитровский мост свободен!»*, *«Троллейная переезд открыт!»*, *«На Большевистской авария»*, *«Спасибо за инфу!»*.
   - Геопривязка сообщений с переходом к точке на карте и реакции (`👍`, `🤝`, `⚠️`, `🔥`).

7. **Построение маршрута с оценкой рисков (/route)**
   - Интеграция с OSRM (Open Source Routing Machine)
   - Анализ инцидентов вдоль пути: автоматический подсчёт задержки (+12 мин из-за переезда, +7 мин из-за ДТП)

7. **Профиль и репутация водителя (/profile)**
   - Уровни: *Новичок, Водитель, Активный водитель, Наблюдатель, Эксперт района*
   - Прозрачный рейтинг (на основе точности сообщений и подтверждений)

8. **Панель модерации (/admin)**
   - Сводка активности за день: 1 248 сообщений, 743 подтверждения, 218 вопросов
   - Лидерборд активных районов Новосибирска (Ленинский, Октябрьский, Кировский, Центральный)
   - Модерация событий: Скрыть, Восстановить, Разрешить, Удалить
   - Управление водителями: блокировка / разблокировка
   - Управление АЗС: добавление новых станций и актуализация цен

9. **Система Web Push уведомлений (VAPID)**
   - Реализована доставка системных пуш-уведомлений о критических событиях:
     - 🚗 Серьёзные ДТП и перекрытые полосы
     - 🚧 Закрытые Ж/Д переезды
     - 🛣️ Перекрытия движения и сильная гололедица
   - Подписаться и проверить доставку можно в профиле водителя (**«Профиль» → «Web Push (VAPID)»**).
   - В панели администратора доступна кнопка экстренной проверки: **«Тестовый пуш»**.
   - При клике на уведомление приложение фокусируется и сразу открывает карточку события на карте.

10. **PWA и мобильный UX**
   - Установка на экран Домой (Chromium + пошаговый гид для iOS Safari)
   - Оффлайн-кэширование тайлов карты и данных через Service Worker
   - Поддержка Telegram Mini App (`TelegramService.ready()`)

## 📦 Установка и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется на порту `3000`: `http://localhost:3000`.

### 3. Сборка для Production
```bash
npm run build
npm run preview
```

## 🗄️ База данных и миграции Supabase

Вся схема базы данных описана в файлах:
- `supabase/migrations/20261004000000_roadlive_init.sql` — таблицы, индексы, RLS, триггеры и SQL-функция `refresh_event_status()`
- `supabase/seed.sql` — справочные данные по Новосибирску:
  - город и 10 районов Новосибирска
  - 6 АЗС (Газпромнефть, Лукойл, Роснефть, Прайм, Татнефть)

### Применение миграций:
```bash
supabase db push
# или через Supabase CLI:
supabase migration up
supabase db reset
```

## ⚙️ Переменные окружения (.env)

Пример конфигурации (`.env.example`):
```env
# Supabase
VITE_SUPABASE_URL="https://your-project.supabase.co"
VITE_SUPABASE_ANON_KEY="your-anon-key"

# Map Provider
VITE_MAP_PROVIDER="osm"

VITE_TELEGRAM_BOT_USERNAME="roadlive_nsk_bot"

VAPID_PRIVATE_KEY=""
```

*Примечание: Переменные Supabase обязательны — без них приложение не получает данные.*

## 👥 Вход и аккаунты

Приложение работает только внутри Telegram Mini App: профиль создаётся автоматически из данных
аккаунта Telegram при первом открытии. Отдельных тестовых аккаунтов и демо-входа нет.

## 🏙️ Как добавить новый город

1. Добавьте строку в таблицу `cities` (Supabase):
```sql
insert into cities (id, name, latitude, longitude, default_zoom, is_active)
values ('ekb-city-05', 'Екатеринбург', 56.8389, 60.6057, 12, true);
```
2. Добавьте районы города в таблицу `districts`.

---

## ➕ Как добавить новую категорию событий

1. В `src/types/index.ts` добавьте тип в объединение `EventType`:
```typescript
export type EventType = ... | 'flooding';
```
2. В `src/components/events/CreateEventModal.tsx` добавьте категорию и быстрые подтипы в массив `categories`.
3. В `src/components/map/RoadMap.tsx` добавьте иконку маркера в свитч `ev.type`.
